# Modelo de requisição

`requisicao-materiais.pdf` contém quatro recortes vetoriais do formulário fornecido
pelo usuário em 30/09/2026: cabeçalho, aviso, títulos da tabela e assinatura.
Os nomes, destino, material, patrimônio e data do exemplo foram removidos.
O arquivo é um recurso de composição, não um termo emitido.

Referência original: **30.09.26 - MICROONDAS- PA LARANJEIRAS.pdf**.
Recortes A4, em pontos medidos a partir do topo: 0–253, 331,5–363,
388,8–424,8 e 620–653. O campo do solicitante no cabeçalho é limpo antes
da composição. As outras informações fixas do cabeçalho são preservadas.

O gerador em `js/modules/execucao/requisicao.pdf.js` incorpora essas partes e
preenche os dados congelados da requisição. Não colocar dados de um exemplo
particular nos componentes usados pelo sistema.
